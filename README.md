# Rahul Nair - Personal Portfolio (Version 11)

Static multi-page portfolio for GitHub Pages. Upload the contents of this folder to the root of `rhnair11.github.io`.

## Pages
- `index.html` - Home
- `about.html` - About, now using the supplied campus photo
- `experience.html` - Professional experience, education and credentials
- `projects.html` - Varun Beverages and Eicher Motors modelling reports, plus ISBR certificates
- `contact.html` - Contact form that opens the visitor's default email app

## Included source materials
- `assets/varun-beverages-financial-model.pdf` - submitted Varun Beverages report
- `assets/eicher-motors-financial-model.pdf` - submitted Eicher Motors report
- `assets/certificate-credit-finance.png` - ISBR Credit Finance certificate
- `assets/certificate-financial-modelling.png` - ISBR Financial Modeling certificate
- `assets/rahul-about-campus-bw.jpg` - supplied campus photo used on About page

Project summaries describe the submitted reports' contents. Historical report figures and model assumptions are not presented as current investment advice.
