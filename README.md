# Rahul Nair - Personal Website

A responsive, multi-page personal portfolio with a modern editorial design. Built with plain HTML, CSS and JavaScript so it is easy to understand and edit later. No framework, package installation or build step is required.

## Pages

- `index.html` - home page and introduction
- `about.html` - background, interests and working style
- `experience.html` - experience, education and certifications
- `projects.html` - portfolio project concepts and case-study layouts
- `contact.html` - contact details and a form that prepares an email
- `styles.css` - typography, colours, layout and mobile styling
- `script.js` - mobile navigation, current year and contact-form behavior

## Open the website

1. Download and extract the ZIP.
2. Open the `rahul-portfolio` folder.
3. Double-click `index.html` to open the site in your browser.

You can also open the folder in Visual Studio Code. For live refresh while editing, install the Live Server extension and choose **Open with Live Server** on `index.html`.

## Publish for free with GitHub Pages

1. Create/sign in to a GitHub account.
2. Create a repository named `rahul-portfolio`.
3. Upload the *contents* of this folder to the repository root (not the ZIP itself).
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the URL shown in the Pages settings.

Google Fonts are used for the intended typography. If unavailable, the site falls back to system fonts.
